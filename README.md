# Hi, I'm Anirv!

Curious builder exploring **robotics, coding, and real-world problem solving**. Always learning, always creating.

I'm a 9th Grade student who likes turning ideas into things that actually run — games, hardware, and small tools that solve a problem I ran into. I keep a build journal for most projects because I think the interesting part is what broke and why I changed direction.

## What I'm building

I tend to work across three areas:

### Robotics & hardware
- **[gaming-mouse](https://github.com/TheCuriousBuilder/gaming-mouse)** — a custom gaming mouse with 5 programmable keys, taken from 3D design and a bill of materials all the way to a final prototype, with a full build journal.
- **[fll-mission-strategy](https://github.com/TheCuriousBuilder/fll-mission-strategy)** — a data-driven planner that analyzes FIRST Lego League missions (difficulty, time-to-complete, success rate) to recommend the best scoring strategy for a 2:30 match.

### Games & engines
- **[star-empire-sim](https://github.com/TheCuriousBuilder/star-empire-sim)** — a 2D space-strategy game in Python/Pygame: explore planets, manage resources, build fleets, and battle a basic enemy AI.
- **[emotion-adaptive-game](https://github.com/TheCuriousBuilder/emotion-adaptive-game)** — a game that adjusts its difficulty in real time based on how the player is actually performing.
- **[arena-forge-engine](https://github.com/TheCuriousBuilder/arena-forge-engine)** — a 2D Super Smash Bros–style fighting game built in Python.
- **[shooter-game-2d](https://github.com/TheCuriousBuilder/shooter-game-2d)** — a 2D shooter built in Python/Pygame.

### Learning & data tools
- **[mathmind-expression-explorer](https://github.com/TheCuriousBuilder/mathmind-expression-explorer)** — teaches a computer to read and solve math expressions the way students learn PEMDAS.
- **[study-habit-insights](https://github.com/TheCuriousBuilder/study-habit-insights)** — a data-science project analyzing focus, study habits, and procrastination patterns.

## Tools I use
`Python` · `Pygame` · 3D design (STL) · `C++` · `JavaScript` · `Git`

## What I'm learning right now
Learning how parsers work, and  why my game lags when there are too many enemies on screen.
